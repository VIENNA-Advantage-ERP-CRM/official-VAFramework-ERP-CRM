# VIENNA Advantage ERP/CRM 4.x — now Onfinity

This is the single-solution repository of the **4.x line** of VIENNA Advantage ERP/CRM: framework, base libraries and the ERP application in one Visual Studio solution (`ModelLibrary`, `VIS`, `ViennaBase`, `ViennaAdvantageWeb`). It is kept for reference and for the forks and stars it carries.

**VIENNA Advantage is now Onfinity.** The product, the company and the code are the same; the current source is in three repositories, built in this order:

1. [Official-VABaseFiles](https://github.com/VIENNA-Advantage-ERP-CRM/Official-VABaseFiles) — base and core libraries, the generated model classes, the print engine
2. [Official-VAFramework](https://github.com/VIENNA-Advantage-ERP-CRM/Official-VAFramework) — the Application Dictionary, workflows, the HTML5 client
3. [Official-VAStandard-ERP-CRM](https://github.com/VIENNA-Advantage-ERP-CRM/Official-VAStandard-ERP-CRM) — the ERP and CRM application

Onfinity is an open source ERP and CRM in C#/.NET: accounting, purchasing, sales and CRM, inventory and warehouse, projects, fixed assets and HR on one database, with a low-code Application Dictionary underneath. It runs on Windows Server (IIS) with PostgreSQL or Oracle; users work in the browser.
